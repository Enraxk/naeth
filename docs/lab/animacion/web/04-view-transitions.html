web 04 · View Transitions mismo documento: `document.startViewTransition`

Fuente: MDN, «Using the View Transition API». Soporte (web-features, 19/09/2026): Baseline octubre 2025 (Chrome 111, Firefox 144, Safari 18); entre documentos (@view-transition { navigation: auto }) Chrome 126 y Safari 18.2, Firefox no.

Pregunta aislada: pulsa el lomo de Naeth y luego la portada. El navegador anima solo el cambio de tamaño y posición entre las dos instantáneas. ¿Sirve esto como base de «sacar el libro» o se ve como una foto que se estira (que es lo que es)?

Qué mirar

Lo que hace bien: el DOM cambia de verdad (dos componentes distintos) y aun así hay continuidad, sin calcular nada. Lo que no puede hacer: girar un objeto 3D o mostrar caras que no estaban en la instantánea; las instantáneas son imágenes planas. Para el libro es útil para lo que ES un cambio de vista (portada → índice → página), no para el vuelo del objeto. Aviso: el grupo anima width/height del pseudoelemento (lo dice MDN), pero son capas del compositor, no layout del documento.

Fuente: MDN, «CSS scroll-driven animations». Soporte (web-features, 19/09/2026): no es Baseline: Chrome 115, Safari 26, Firefox no. En Helium (Chromium 153) funciona; en Firefox la columna A no anima y la B tampoco (misma API por JS).

Pregunta aislada: haz scroll en las dos columnas. ¿La barra y las tarjetas siguen al dedo sin retraso (la animación va atada al scroll, no al tiempo)? ¿Se nota diferencia entre CSS (A) y JS+WAAPI (B)?

Tarjeta 3. Con animation-timeline la duración no cuenta: el progreso es el scroll.
Tarjeta 4. Y el easing por defecto es lineal respecto al scroll.

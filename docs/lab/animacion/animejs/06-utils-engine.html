Qué mirar

utils.set(target, { x: 10, rotate: 45 }) escribe sin animar (es un animate de duración 0) y es lo que se usa para el estado inicial; utils.get(target, 'x', 'px') lee con unidad; utils.remove(target) mata todas las animaciones del target (limpieza al desmontar un componente si no se usa createScope). utils.damp(a, b, dt, factor) es la interpolación independiente del refresco para bucles a mano (lab web/06, la caja A hecha bien). engine.pauseOnDocumentHidden es lo que hace que en el panel del navegador integrado oculto no corra nada.

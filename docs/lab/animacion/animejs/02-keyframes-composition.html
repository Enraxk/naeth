animejs 02 · keyframes y composition las dos formas de keyframes, y qué pasa al interrumpir

Fuente: src/animation/animation.js:132-215 (generateKeyframes: array de objetos con duration por paso, u objeto por porcentaje {'0%':…, '50%':…} que reparte la duration total), src/animation/composition.js:95-270 (composeTween: replace recorta el tween anterior en el instante en que arranca el nuevo; blend lo suma en una animación aditiva aparte; none no mira a nadie).

Pregunta aislada: lanza y a mitad pulsa «interrumpir: vuelve al origen». Fila 1 (replace, el defecto): la nueva animación toma el mando desde donde estaba, sin salto. Fila 2 (none): las dos escriben a la vez y la caja tiembla. Fila 3 (blend): la vuelta se SUMA a la ida y la caja hace un arco. ¿Cuál quieres para «clic a mitad de sacar el libro»?

1 · composition: 'replace' (defecto)

2 · composition: 'none'

3 · composition: 'blend' (aditivo)

4 · keyframes por porcentaje: {'0%','40%','100%'} con ease por tramo

Qué mirar

Forma array: keyframes: [{ x: 300, duration: 800, ease: 'outQuad' }, { y: -40, duration: 300 }, { x: 600, y: 0, duration: 500 }]; cada paso lleva su duración y su ease. Forma porcentaje: keyframes: { '0%': { x: 0 }, '40%': { x: 400, ease: 'outExpo' }, '100%': { x: 600 } } con una sola duration; el ease de cada clave se aplica al tramo que LLEGA a ella (emula WAAPI, animation.js:196-203). Lo importante para el libro: replace es exactamente «interrumpible con continuidad» (regla 11); es el defecto salvo con 1000 targets o más, que pasa a none por rendimiento (animation.js:273).
